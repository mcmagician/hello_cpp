插入排序 Insertion Sort

就像打牌时整理手里的牌：每拿到一张新牌，就从左到右找到它该放的位置，插入进去。 下面用「扑克牌排序」的直觉，配动画带你一步步看懂。

什么是插入排序

插入排序（Insertion Sort）是一种简单的排序算法。它把工作区分成「已排序」和「未排序」两部分：

  1. 默认第 1 个元素已经排好序（手里第一张牌）。
  2. 依次取出下一个未排序的元素（下一张牌）。
  3. 把它和前面已排序的元素从右往左比较，找到合适位置插入。
  4. 重复直到所有元素都排好。

因为每次都是「插入」到已排序序列的正确位置，所以叫插入排序。

伪代码

for i = 1 to n-1:
    key = a[i]
    j = i - 1
    while j >= 0 and a[j] > key:
        a[j+1] = a[j]   // 后移
        j -= 1
    a[j+1] = key        // 插入

复杂度

情况时间说明
最好O(n)数组已有序，每次比较一次就插入
最坏O(n²)数组逆序，每次都要移到最前
平均O(n²)双重循环
空间O(1)原地排序，只需常数额外空间

什么时候用

稳定排序 相同元素不改变先后顺序。

数据量小、或基本有序时非常高效，也常作为快排、归并排序在小区间上的子排序（如 std::sort 的 introsort）。 数据量大、完全无序时不推荐。
