CSP-J · 二分 / 贪心 / DP / 搜索

这四种不是「四种具体代码模板」，而是四种想问题的方式。 初赛爱考概念与对比；机考要能认题、选对方法、写出基础实现。 本页按 CSP-J 难度讲解，并配有简单演示。

1. 一句话总览

二分 Binary Search

有序 / 单调 → 每次砍掉一半答案区间，快速定位。

贪心 Greedy

每一步选「眼前最优」，拼出整体最优（要证明或凭经典模型）。

动规 DP

大问题拆成小问题，记结果、避免重复算，用转移方程递推。

搜索 Search

在状态空间里系统枚举：DFS 深挖、BFS 一层层扩，找可行解/最短路。

思想 核心直觉 CSP-J 常见题 典型复杂度感觉
二分 砍一半 有序查找、二分答案（最小最大值） 很快，约 log n
贪心 每步最优 排序后取、活动安排、简单凑数 常是 n 或 n log n
动规 记表递推 背包、爬楼梯、路径计数、最长上升 常是 n、n²、背包 nW
搜索 枚举状态 迷宫、连通块、排列组合、回溯 可能指数级，要剪枝 / 换 BFS
应试直觉 看到「有序」「单调」「最小的最大」→ 先想二分； 「按某种规则排序再取」→ 贪心； 「最优解 / 方案数，且有重叠子问题」→ DP； 「走格子 / 枚举所有可能」→ 搜索。

2. 二分算法是什么？

二分：在单调的序列或答案区间上，反复取中点判断，丢掉不可能的一半。 前提几乎总是：存在「左边不满足 / 右边满足」这类分界。

经典：有序数组找数

// 在有序 a[1..n] 中找 x，找不到返回 -1
int binary_search(int a[], int n, int x) {
    int L = 1, R = n;
    while (L <= R) {
        int mid = (L + R) / 2;
        if (a[mid] == x) return mid;
        if (a[mid] < x) L = mid + 1;
        else R = mid - 1;
    }
    return -1;
}

进阶考法：二分答案

不一定在数组里找元素。若「答案越大越容易满足 / 越难满足」呈单调， 可以对答案本身二分，再写一个 check(mid) 判断是否可行。

例：木头切割 要切出至少 K 段长度为 x 的木头 → 对 x 二分， check(x) = 能否切出 ≥ K 段。求最大的可行 x。
易错 数组无序不能直接二分；边界写成死循环（L/R 更新错）； mid = (L+R)/2 在极大范围时可能溢出（CSP-J 少见，知道即可）。

3. 贪心是什么？

贪心：每一步都选当前看起来最好的选择，且假设这样能得到全局最优。 它不回溯、通常也不记很多状态，代码往往很短——但不是每题都能贪。

经典：活动选择（结束早的优先）

若干活动有开始、结束时间，选最多互不冲突的活动 → 按结束时间升序，能选就选。

// 假设已按结束时间排序：ed[i]
int ans = 0, last = -1;
for (int i = 0; i < n; i++) {
    if (st[i] >= last) {   // 不冲突
        ans++;
        last = ed[i];
    }
}

CSP-J 常见贪心信号

  • 排序后从头扫一遍就能出答案
  • 「每次取最大 / 最小」明显合理（如找零钱面值互为倍数时）
  • 题目保证或经典模型：区间覆盖、活动安排、Huffman 思想等
贪心陷阱 「看起来最优」≠「一定最优」。反例：普通找零钱（面值 1,3,4，凑 6）贪心取 4+1+1=3 枚， 实际 3+3=2 枚更优。拿不准时用 DP / 搜索验证，或先想反例。

4. 动态规划是什么？

动态规划（DP）：把问题拆成子问题，用数组记下每个子问题的最优解（或方案数）， 再按转移方程从小到大填表。关键：子问题会重叠，且满足最优子结构（大问题的最优由小问题最优推出）。

入门：爬楼梯 / 斐波那契型

到第 i 级可以从 i-1 或 i-2 走来：

int f[105];
f[1] = 1; f[2] = 2;
for (int i = 3; i <= n; i++)
    f[i] = f[i - 1] + f[i - 2];

CSP-J 常考：01 背包（简化）

每件物品最多选一次，容量为 W，求最大价值：

int dp[1005];  // dp[j] = 容量 j 时的最大价值
// 对每件物品 i（体积 w，价值 v）：
for (int j = W; j >= w; j--)
    dp[j] = max(dp[j], dp[j - w] + v);
写 DP 的三步 ① 状态是什么（dp[i] / dp[i][j] 含义）→ ② 转移怎么写 → ③ 初值与答案在哪（dp[n] 还是 max(dp)）。
和递归搜索的区别 朴素递归会重复算同一状态；DP 把结果存下来（记忆化或递推），把指数暴搜压成多项式。

5. 搜索算法是什么？

搜索：在「所有可能状态」里系统查找。CSP-J 主要掌握：

  • DFS（深度优先）：一条路走到底，再回溯换路。适合：连通块、排列、回溯剪枝。
  • BFS（广度优先）：一层层扩展。适合：迷宫最短步数（边权都为 1）。

DFS 骨架（连通块 / 泛洪）

int dx[] = {0, 0, 1, -1};
int dy[] = {1, -1, 0, 0};

void dfs(int x, int y) {
    vis[x][y] = 1;
    for (int k = 0; k < 4; k++) {
        int nx = x + dx[k], ny = y + dy[k];
        if (合法 && !vis[nx][ny] && 是目标)
            dfs(nx, ny);
    }
}

BFS 骨架（最短步数）

// 队列里存坐标，dist[][] 记步数
queue<pair<int,int>> q;
q.push({sx, sy});
dist[sx][sy] = 0;
while (!q.empty()) {
    auto [x, y] = q.front(); q.pop();
    for (int k = 0; k < 4; k++) {
        int nx = x + dx[k], ny = y + dy[k];
        if (合法 && dist[nx][ny] == -1) {
            dist[nx][ny] = dist[x][y] + 1;
            q.push({nx, ny});
        }
    }
}
和 flood fill 的关系 泛洪填充就是搜索的一种应用（DFS/BFS 染连通块）。项目里另有 floodfill-tutorial.html 可配合看。
易错 忘记 vis / dist 标记导致死循环； 求最短步却用 DFS（不一定最短）； 边界越界、四连通/八连通搞混。

6. 四者有什么区别？怎么选题？

对比点 二分 贪心 DP 搜索
在干什么 缩小答案范围 每步定一个选择 填表算最优/计数 枚举所有可能
要不要回溯 否 否 否（递推） DFS 要；BFS 一般不
关键前提 单调性 贪心策略正确 最优子结构 + 重叠 状态可枚举完
和「最优」关系 常求边界最优 直接冲最优 系统地求最优 可求可行/最短；全枚举也可最优但慢
失败时会怎样 无单调 → 错 策略错 → WA 转移错/维数不够 → WA 爆时间 / 爆栈

做题决策树（临场可用）

  1. 数据有序 / 答案可二分 + 能写 check？→ 二分
  2. 排序后扫一遍、有经典贪心模型、能想通为什么对？→ 贪心
  3. 求最优或方案数，子问题重复，能定义状态？→ DP
  4. 走迷宫、连通、排列、状态不多？→ 搜索（最短步优先 BFS）
  5. 贪心拿不准 → 小数据用搜索验证；搜索太慢 → 想 DP / 剪枝 / 二分
它们会组合出现 例如：二分答案 + 贪心 check；搜索里用记忆化变成 DP； 贪心排序后再二分。考试不必死磕「纯种」，认准主思路即可。
