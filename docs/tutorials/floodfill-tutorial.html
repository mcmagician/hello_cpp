CSP-J · 泛洪填充入门教程

泛洪填充就像画图软件里的「油漆桶」：点一下，颜色就会沿着相连的格子一路涂开。 本页用大白话 + 动画讲清楚；不要求你先懂高深名词。

1. 泛洪填充是什么？

想象一张方格纸地图：

  • 有的格子是陆地（可以走）
  • 有的格子是水（不能走）

你从某一格陆地出发，不断走到上下左右相邻的陆地，把整片连在一起的陆地都「涂」一遍—— 这就叫泛洪填充（英文 Flood Fill，可以记成「洪水一样往外漫」）。

生活例子题目里对应什么
油漆桶一键填色 把同一片区域改成同一个标记
数地图上有几块大陆 数有几片「连在一起的陆地」
迷宫里从入口能走到哪 从起点出发，能到达哪些格子
一句话记住 从一个格子出发 → 把所有能连上的同类格子都处理完。

2. 格子地图与四个方向

考试里地图通常用二维数组存，比如 a[i][j]： i 是第几行，j 是第几列。

CSP-J 最常见的是四连通：只能走上、下、左、右（不能斜走，除非题目明文允许）。

代码里常用两个小数组表示四个方向（背下来很有用）：

int dx[4] = {-1, 1, 0, 0};  // 行：上、下、不变、不变
int dy[4] = {0, 0, -1, 1};  // 列：不变、不变、左、右
考试提醒 走之前先检查：有没有走出地图边界？目标格子是不是允许走的？有没有已经涂过？

3. 只需记住三条规则

别被「某某搜索」这种名字吓到。你只要按下面做就行：

  1. 能不能进？ 出界、是水、已经涂过 → 立刻停，不要进。
  2. 进来就先涂上。 改成「已访问」或换成新颜色，避免以后又涂回来。
  3. 再看四个邻居。 对上、下、左、右各试一次，能进就继续涂。

怎么「继续」有两种写法，效果一样，选一种练熟即可：

写法大白话适合
函数自己再调用自己
（有人叫递归 / 深度优先）		 走到一格，马上钻进邻居，一路钻到底，再回头 代码短，CSP-J 很常见
用队列排队
（有人叫广度优先）		 像买票：先处理排在前面的格子，再处理新来的 不容易「递归太深」炸栈
给初中生的建议 先学会「函数自己调用自己」那一版。名字先不用背；会写、会查边界，比背名词重要。

5. 怎么写成 C++？

下面是「函数自己调用自己」的版本。读注释就够理解流程：

int n, m;                 // 地图有 n 行 m 列
int a[105][105];         // 1=陆地, 0=水
bool vis[105][105];      // 有没有涂过
int dx[4] = {-1, 1, 0, 0};
int dy[4] = {0, 0, -1, 1};

void flood(int x, int y) {
    // 规则1：不能进就返回
    if (x < 1 || x > n || y < 1 || y > m) return;
    if (a[x][y] == 0 || vis[x][y]) return;

    // 规则2：进来先涂
    vis[x][y] = true;

    // 规则3：尝试四个邻居
    for (int i = 0; i < 4; i++) {
        flood(x + dx[i], y + dy[i]);
    }
}
为什么要 vis？ 如果不标记「已经来过」，算法会在两个相邻格子之间来回走，永远停不下来。

也可以边走边改地图（少开一个数组）

有的题允许你直接把陆地改成水，表示「涂过了」：

void flood(int x, int y) {
    if (x < 1 || x > n || y < 1 || y > m) return;
    if (a[x][y] == 0) return;  // 水，或已被改成 0
    a[x][y] = 0;                   // 涂掉
    for (int i = 0; i < 4; i++)
        flood(x + dx[i], y + dy[i]);
}

6. 经典题：数有几座岛

思路超级直接：

  1. 扫完整张地图。
  2. 碰到一块还没涂过的陆地 → 岛屿数量 +1，然后从这里泛洪，把整座岛涂完。
  3. 继续扫，直到结束。
int ans = 0;
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++) {
        if (a[i][j] == 1 && !vis[i][j]) {
            ans++;
            flood(i, j);   // 把这座岛全部涂掉
        }
    }
}
cout << ans << endl;
为什么这样是对的？ 每找到一个新起点，就说明发现了一座新岛；泛洪会把这座岛上的格子都标记掉，所以不会重复计数。

7. 易错点速查

  1. 忘了判边界 → 数组越界，程序可能崩溃或答案错乱。
  2. 忘了标记已访问 → 死循环，或超时。
  3. 下标从 0 还是从 1：读题和读入方式要一致；本教程示例用 1…n。
  4. 斜着能不能走：默认四连通；八连通要题目明确说。
  5. 地图太大 + 递归太深：极少数情况可能栈溢出；这时可改用队列写法（了解即可）。
口诀 先查「能不能进」→ 再「涂上」→ 最后「扩四个邻居」。顺序别反，尤其不要「还没涂就先扩邻居」。

8. 考试小抄（临考看这页）

#include <iostream>
using namespace std;

int n, m;
int a[105][105];
bool vis[105][105];
int dx[4] = {-1, 1, 0, 0};
int dy[4] = {0, 0, -1, 1};

void flood(int x, int y) {
    if (x < 1 || x > n || y < 1 || y > m) return;
    if (a[x][y] == 0 || vis[x][y]) return;
    vis[x][y] = true;
    for (int i = 0; i < 4; i++)
        flood(x + dx[i], y + dy[i]);
}

int main() {
    cin >> n >> m;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            cin >> a[i][j];

    int ans = 0;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            if (a[i][j] == 1 && !vis[i][j]) {
                ans++;
                flood(i, j);
            }
    cout << ans << endl;
    return 0;
}
