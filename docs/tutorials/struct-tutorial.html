CSP-J · 结构体 struct 入门教程

结构体把「好几类相关数据」打包成一个类型。CSP-J 机考里常用来存学生、坐标、题目记录等。 学会定义、访问、数组、简单排序，就够应付大多数题。

1. 结构体是什么？

普通变量一次只能存一种类型；结构体可以一次存多种类型。

场景不用结构体用结构体
存 3 个学生的姓名和成绩 name[3] + score[3] 两个数组，靠下标对应 一个 Student stu[3]，每人信息绑在一起
平面坐标 x、y 两个变量 Point p;，里面有 p.x、p.y
应试直觉 题目里出现「每个人有多个属性」「每条记录有多项数据」→ 优先想结构体。

2. 怎么定义？

最常见写法（推荐背下来）：

struct Student {
    string name;   // 姓名
    int score;     // 成绩
};                 // 别忘了分号！

Student a;         // 定义一个学生变量
Student b = {"Amy", 95};  // 定义并初始化

成员可以是各种类型

struct Point {
    int x, y;
};

struct Book {
    string title;
    double price;
    int pages;
};
易错：结尾分号 struct ... { ... }; 最后那个分号漏了，编译直接报错。考试时写完先检查！

3. 访问成员：用点号 .

Student s;
s.name = "Bob";
s.score = 88;
cout << s.name << " " << s.score << endl;

读入也很常见：

Student s;
cin >> s.name >> s.score;
初赛可能问 「访问结构体成员用什么运算符？」→ 答案是 点运算符 . （指针访问才是 ->，CSP-J 机考少用，知道即可。）

4. 结构体数组（机考超常见）

Student stu[100];   // 最多 100 个学生
int n;
cin >> n;
for (int i = 0; i < n; i++) {
    cin >> stu[i].name >> stu[i].score;
}
// 找最高分
int best = 0;
for (int i = 1; i < n; i++) {
    if (stu[i].score > stu[best].score)
        best = i;
}
cout << stu[best].name << endl;
记忆口诀 数组下标在前，成员名在后：stu[i].score，不是 stu.score[i]。

5. 和函数一起用

可以当参数传递；想在函数里改它的内容，用引用（比指针更常考、更好写）：

void addBonus(Student &s, int bonus) {
    s.score += bonus;   // 改的是原来的学生
}

Student a = {"Amy", 90};
addBonus(a, 5);        // a.score 变成 95

只读、不修改，可以传值，或传 const Student &（进阶，了解即可）。

6. 排序常考写法

按成绩从高到低排序（CSP-J 可用 sort + 自定义比较）：

#include <algorithm>
using namespace std;

bool cmp(Student a, Student b) {
    return a.score > b.score;  // 分数高的排前面
}

// ...
sort(stu, stu + n, cmp);

多关键字也很常见：先比分数，分数相同再比姓名字典序：

bool cmp(Student a, Student b) {
    if (a.score != b.score)
        return a.score > b.score;
    return a.name < b.name;
}
机考提醒 记得 #include <algorithm>；比较函数返回 true 表示「a 应该排在 b 前面」。

7. 易错点速查

  1. 定义结构体后漏分号。
  2. 写成 stu.score[i]，正确是 stu[i].score。
  3. 两个结构体不能直接用 > 比较整份，要比较具体成员，或写 cmp。
  4. 结构体可以互相嵌套，但 CSP-J 一般一层就够，别自己搞复杂。
  5. 数组开太大可能爆栈；人数上限看清题目，常见 stu[1005] 一类。

8. 考试小抄（临考看这页）

// 模板：读入 n 个学生，按分数降序输出姓名
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

struct Student {
    string name;
    int score;
};

bool cmp(Student a, Student b) {
    return a.score > b.score;
}

int main() {
    int n;
    cin >> n;
    Student stu[105];
    for (int i = 0; i < n; i++)
        cin >> stu[i].name >> stu[i].score;
    sort(stu, stu + n, cmp);
    for (int i = 0; i < n; i++)
        cout << stu[i].name << " " << stu[i].score << endl;
    return 0;
}
笔试可能考 定义语法、成员访问、结构体数组含义、点号与箭头区别。机考重点是能写、能排、能找最值。
